# Project Data

The Week 12 final project uses these supplied files:

- `customers.db` — customer profiles and locker data
- `delivery_logs.csv` — shipment status events and driver notes
- `ground_truth.csv` — expected exception, resolution, escalation, and tone labels
- `exception_resolution_playbook.pdf` — exception-handling policy and communication guidance

These source files are kept separate from credentials. Add the supplied data files here when working locally or when committing project assets in a dedicated data branch/PR.
